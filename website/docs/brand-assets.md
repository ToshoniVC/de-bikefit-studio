# Brand assets (logo, mark, icons)

The logo set Toshoni supplied on 17 October 2026 (generated with Gemini, five SVGs), renamed
`debikefitstudiologo-*` and kept under `public/brand/`. Everything the site shows is derived
from these files; nothing else carries a logo.

| File | What | Used by |
| --- | --- | --- |
| `public/brand/debikefitstudiologo-horizontal.svg` | the lockup: burgundy stamp + wordmark, 250×52, for light grounds | downloads and print; not rendered by the site (see "Fonts") |
| `public/brand/debikefitstudiologo-horizontal-inverted.svg` | the same in cream, for burgundy grounds | idem |
| `public/brand/debikefitstudiologo-stacked.svg` | the centred lockup, 200×160 | idem |
| `public/brand/debikefitstudiologo-icon-512.svg` | the square mark, full-bleed burgundy, 512×512 | source of the PNG icons |
| `public/brand/debikefitstudiologo-favicon-32.svg` | the mark at 32×32 with a 4 px radius | `src/app/icon.svg` (the SVG favicon) and the source of `favicon.ico` |
| `public/brand/debikefitstudiologo-mark.svg` | the stamp alone (burgundy), cut from the horizontal lockup | the header (`components/studio/logo.tsx`) |
| `public/brand/debikefitstudiologo-mark-inverted.svg` | the stamp alone (cream) | the footer and the admin sidebar; drawn inline in the share image (`lib/studio/og-image.tsx`) |
| `public/brand/debikefitstudiologo-icon-512.png` | rendered from the 512 SVG | the Organization logo in the JSON-LD (`app/(studio)/layout.tsx`) unless an admin set a logo under Instellingen → Site |
| `src/app/apple-icon.png` | 180×180, rendered from the 512 SVG | `<link rel="apple-touch-icon">` (Next file convention) |
| `src/app/favicon.ico` | 16, 32 and 48 px PNG entries | `/favicon.ico` (Next file convention) |
| `src/app/icon.svg` | copy of the favicon SVG | `<link rel="icon" type="image/svg+xml">` (Next file convention) |

The three PNG/ICO files are generated by `npm run brand:icons` (`scripts/brand-icons.mts`,
needs `sharp`, which the app already depends on) and committed, so a build never runs it. Run it
again after a brand SVG changes and commit the outputs.

**Fonts.** The supplied lockups set their wordmark as SVG `<text>` in Bebas Neue, Oswald or
Impact, none of which a visitor's browser is guaranteed to have, so the site never renders those
files as images. The header, footer and admin show the stamp as an image and the two lines "De
Bikefit" / "Studio" as HTML in the site's display face (Barlow, `--ds-font-display`), styled
after the SVG (`.studio-logo` in `globals.css`): the same lockup, in a font that loads.

**Colours.** The SVGs carry their own values (burgundy `#3B1821`, cream `#FBF9F5`, taupe
`#D5C7BC`, mauve `#7A6467`), close to but not identical with the design tokens
(`--ds-burgundy-700 #3e1420`, `--ds-bone-50 #fdfbf7`, `--ds-cream-300 #edd5b9`,
`--ds-mauve-500 #8c6a5a`). Assets may keep their values; components only use tokens
(CLAUDE.md §3), which is what the lockup's text does. The old `public/logo.svg` (a grey bike
drawing with a Montserrat title) was removed on 17 October 2026; the project hub (`/index.html`,
`/logo.svg` at the repository root) and `brand/logo.svg` still carry the old one.
